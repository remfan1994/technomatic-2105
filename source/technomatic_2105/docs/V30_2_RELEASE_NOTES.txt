WHAT CHANGED

This update increases the average level of TECHNOMATIC 2105's generated music
while preserving the music, controls and both earlier v30.1 volume fixes.

The output calibration changes from 1.0 to 1.75. In the linear region that
means +4.86 dB. A wider, gentler peak curve keeps strong samples within the
same full digital range. The ceiling remains 1.0, or 100 percent.

The final constants are:

  fixed gain G = 1.75
  rounding onset K = 0.40
  sample ceiling C = 1.00

K is where smooth rounding begins. It is not a 40-percent output cap.

There is still one fixed output treatment for all tracks and all times.
Android's media volume remains the listener's control. The app does not
reintroduce automatic gain riding, kick ducking, fades, master swells/dips,
coordinated part-volume changes or a lookahead limiter. Individual note
envelopes, accents and rests remain musical behaviors.

MEASURED IMPROVEMENT

Sixteen matched seeds were rendered for 88 seconds each at 48 kHz stereo.
The same [40,88) second excerpts had:

  Median paired loudness increase:      +4.50 LU
  Median paired RMS increase:           +4.52 dB
  Per-track loudness increase:          +3.7 to +4.7 LU
  Median v30.1 loudness:                -14.05 LUFS
  Median v30.2 loudness:                 -9.60 LUFS

Examples at the same source playback setting:

  Slow seed 1013904226:          -14.4 ->  -9.8 LUFS
  Groove seed 2654435761:        -16.0 -> -11.3 LUFS
  Quiet driving 3711502885:      -16.4 -> -11.7 LUFS
  Intense seed 3668339987:       -10.1 ->  -6.4 LUFS

The improvement is average source-audio level. Full-scale peaks alone do
not establish the perceived loudness of a track. These measurements do not
claim the same subjective increase in every song, earbud or environment.

WHY THE GENTLER CURVE

Stronger fixed gain requires more rounding of strong peaks. The first
louder candidate retained the old 0.80 rounding onset; its densest test
produced substantial reconstructed overrange after Opus decoding.

The final 0.40 onset widens the curve while keeping the 1.0 ceiling. It
retains almost all the measured average increase and reduces that test's
overfull decoded sample count by about 85.49% relative to the rejected
1.75/0.80 candidate. It is a measured compromise, not distortion-free gain.

All final native samples in the 16-seed test are finite and bounded; the
largest observed magnitude is 0.998284. Reconstructed/codec peaks remain a
different matter: native reconstructed peaks reach +1.4 dBTP, and the final
intense host Opus excerpt has about 0.483% of decoded samples above full
scale. That is lower than the rejected boosted candidate's 3.328%, but higher
than delivered v30.1's 0.0174% for the same intense excerpt. No universal
clipping-free or subjective-quality claim is made.

MUSIC, FEATURES AND METADATA

The composition engine, instruments, per-song ensemble size, themes,
complementary phrases, slow-jam grammar, note accents and improvisation are
unchanged. All 16 score, amplitude and RNG signatures match v30.1, covering
20,247 scheduled events. Independent reconstruction of the final output
matches all 135,168,000 actual float channel samples exactly.

MusicEngine.cpp changes only two output-revision serialization values.
Every Java source file, AudioEngine, JNI and MusicEngine.h remains byte-
identical to v30.1. The other runtime change is OutputStage's calibration.

Live playback and OGG/FLAC export use the same stronger output. Captured
recipes retain engine=30 and record outputrev=2; embedded audio metadata
records OUTPUT_MASTER_VERSION=2. Automatic seed metadata, full regeneration
recipes, user notes and the metadata editor remain intact. Previously saved
recipes receive the current output when loaded.

Playback controls, latest-20 history and memory behavior remain those of
v30.1. The cancelled scanner/rewind work and postponed track-naming/history
features are excluded from this release.
